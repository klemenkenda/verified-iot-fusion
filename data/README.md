# Data

**No data files are committed to this repository**, except tiny synthetic fixtures that
live with the tests. Everything under this directory other than this file is ignored.

Conventions from section 12 of [the plan](../docs/research_plan.md):

- Raw data is immutable and addressed by checksum.
- Prepared data is regenerated by scripts, never edited in place.
- Configurations contain no machine-specific absolute paths; point at this directory
  through configuration instead.

## Layout

```text
data/
├── raw/         downloaded, immutable, checksummed
└── prepared/    regenerated from raw by adapter scripts
```

## Expected datasets

Roles and commitments are defined in section 8 of the plan.

| Dataset | Role | Source |
| --- | --- | --- |
| Synthetic streams | Temporal oracle and unit fixtures | Generated in-repo |
| NOAA USCRN | Primary temporal dataset | <https://www.ncei.noaa.gov/access/crn/data.html> (hourly update archive) |
| Enefit | Primary dataset | Kaggle competition data |
| Beijing Multi-Site Air Quality | Cross-domain dataset | UCI Machine Learning Repository |
| Open-Meteo / NOAA HRRR | Optional forecast-revision extension | <https://open-meteo.com/en/docs/historical-forecast-api> |
| Intel Berkeley Lab | Optional high-frequency and missing-message tests | <https://db.csail.mit.edu/labdata/labdata.html> |

Record the dataset version and the raw file hashes of every acquisition in the run
manifest so a result can be traced back to the exact bytes it was computed from.
