# Artifacts

Generated outputs: run manifests, compiled feature programs, feature cards, lineage
records, cached LLM responses, figures, and tables.

Everything here is **produced by a command and reproducible from it** — nothing is edited by
hand. Cached raw LLM responses live here so experiments can be rerun from cached candidates
without new API calls; credentials and personal information are removed before archiving.

Large generated files are ignored by git; see [.gitignore](../.gitignore). Commit only the
small artifacts the manuscript cites directly.
